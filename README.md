# Anil Pandey Website

Static website for GitHub Pages.

## Pages

- Main website: `/`
- Spin the Wheel: `/spin-wheel/`
- Lyrics Maker: `/lyrics-maker/`
- Quiz Maker: `/quiz-maker/`

Each project is served from its folder's `index.html`, so the public URLs do not end in `.html`.

## Deploy

Publish the repository root with GitHub Pages. The `CNAME` file configures `pandeyanil.com.np`; set the matching custom domain in the repository's Pages settings and configure DNS for GitHub Pages.
